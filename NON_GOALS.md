# Non-goals (v1)

The following are explicitly **out of scope** for v1. Feature requests in these areas are closed with a link here unless a roadmap change is agreed.

- Manuscript / paper generation and automatic scientific conclusions
- Proposal writing
- Telescope control or observation scheduling execution (visibility *planning* is in scope)
- Raw data reduction / calibration pipelines (CASA, JWST/HST pipelines, IRAF-style reduction). Downloading and inspecting *reduced* products is in scope.
- Large HPC jobs, cluster submission
- Arbitrary internet browsing by the agent
- Collaboration features: teams, shared workspaces, RBAC, server tenancy
- Mobile app (read-only mobile may come later)
- Fully autonomous long-running research without user oversight
- School, outreach, amateur-observing and undergraduate-teaching optimisations
- A connector marketplace (a plugin *spec* is in scope; a marketplace is not)
- Integrating more than the MVP sources before the M2 benchmark passes
