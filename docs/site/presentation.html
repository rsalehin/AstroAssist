Ask in natural language. Get answers where every number has a unit, an uncertainty, a source, and a re-runnable query — assembled from archives, Astropy and the literature, entirely on your own machine.

M0 complete — green end-to-end FastAPI · LangGraph · React Python 3.11–3.13 BSD-3-Clause
Why

Researchers distrust anything that can’t show its sources

A normal week combines object metadata, catalog measurements, archival observations, papers and Python calculations across SIMBAD, VizieR, ADS and Jupyter.

General chat assistants hallucinate numbers and hide their queries. A beautiful hallucinated table is a product failure.

Core promise

  • Every number: unit, uncertainty, source, query
  • Disagreeing sources shown side by side
  • Failed/substituted sources reported
  • Nothing expensive runs without asking
  • Whole session exports as a runnable bundle
The target

Day-one story — investigate AD Leo

Resolve→ Astrometry→ Distance & velocity→ TESS light curve→ Flares→ Papers→ Reproducible summary

One stellar question exercises nearly every capability: name resolution, coordinates, Gaia astrometry, VizieR photometry, MAST/TESS light curves, physical calculations, plots, papers and citations — with full provenance and a runnable export. If that works, v1 is real.

Architecture

UI → API → orchestration → tools → typed artifacts

Request lifecycle

Nine stages, with a human gate on risk

Ingest→ Resolve→ Route→ Plan→ Preflight ⚠→ Execute→ Supervise→ Synthesize→ Persist

Plan

An explicit DAG of typed steps with declared inputs/outputs — stored as an artifact you can inspect.

Preflight ⚠

Cost estimate per step (queries, rows, bytes, seconds). Over threshold → approve / edit / cancel interrupt.

Synthesize

Answer written from artifact summaries only, citing ids. A post-check rejects numerals with no artifact.

Data model

No naked numbers · no artifact without provenance

Every scientific output is a typed artifact carrying a full Provenance record. Physical numbers are Astropy Quantity / SkyCoord / Time so units survive the wire.

Quality

Deterministic by construction

  • mock model provider replays scripted responses — no API key, ever, in tests
  • Recorded archive fixtures — no live network in unit/component/e2e
  • UI fixtures generated from the Python models → shapes can’t drift
  • Deterministic evaluators: unit, value ± tolerance, provenance completeness
  • make check is the single gate; CI on 3 OSes × 3 Pythons

Deployment · illustrative

Local, for a group of ~20

A · per-workstation (recommended)

Each researcher runs their own instance. Zero shared infra, perfect data isolation, keyring credentials.

uv tool install astroassist
astroassist serve

B · shared appliance

One internal Docker host behind Caddy/nginx (TLS + SSO). Because v1 is single-user, run one isolated instance per person; a shared cache keeps archive traffic polite; central nightly backups.

The app binds 127.0.0.1 and has no built-in auth (a deliberate v1 non-goal) — the reverse proxy provides identity and TLS.
